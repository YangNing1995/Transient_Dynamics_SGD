## Overview

This repository contains the official implementation and supplementary materials for the paper:

**"Noise-Driven Exploration and Transient Freezing Select Flat Minima in Stochastic Gradient Descent"**

**Authors:** Ning Yang, Yikuan Zhang, Chao Tang, and Yuhai Tu  

The codebase consists of two main components:
1.  **Numerical Experiments (PyTorch):** Implementations for training MLPs on MNIST and CNNs on CIFAR-10. This includes specialized tools for loss landscape analysis, such as Hessian spectrum computation and deterministic continuation training protocols.
2.  **Theoretical Modeling (MATLAB):** Simulations of the minimal Two-Valley landscape model to verify the transient-freezing mechanism of flat-minimum selection.

## 📂 Repository Layout

### 1. `Numerical_experiments/` (PyTorch)
Contains training scripts, model definitions, and analysis utilities.

* **Core Modules**
    * `model.py`: Architecture definitions (FCN for MNIST, SimpleCNN for CIFAR-10).
    * `data_utils.py`: Dataset loaders and data transformation helpers.
    * `train.py`: Utilities for the standard training loop.

* **Experiment Drivers**
    * `run_repeat_mlp.py`: Script for repeated training of MLPs on the MNIST subset.
    * `run_repeat_cnn.py`: Script for repeated training of CNNs on the full CIFAR-10 dataset.
    * `continue_training.py`: Implements the deterministic continuation protocol (switching to full-batch GD) to probe the properties of the valley currently occupied by SGD.

* **Landscape Analysis**
    * `hessian_mlp.py`: Hessian eigenspectrum computation for MLPs.
    * `hessian_cnn.py`: Hessian eigenspectrum computation for CNNs.
    * `hessian_continue_training.py`: Hessian analysis specifically for trajectories generated by continuation training.

* **Freezing-Time Analysis**
    * `compute_continuation_endpoint_stats.py`: Runs deterministic continuations on a fixed checkpoint grid and saves endpoint metrics (basin signature, test accuracy, endpoint flatness).
    * `compute_freezing_time.py`: Endpoint-only scanner that estimates the freezing time `t_f` — the earliest checkpoint after which the continuation endpoint stays in the same basin as the final solution.
    * `recompute_freezing_thresholds.py`: Recomputes `t_f` from cached endpoints at different Jaccard-similarity thresholds (robustness check) without re-running any continuation.


### 2. `Two_valleys_model/` (MATLAB)
Contains numerical simulations for the Two-Valley landscape model.

* **Simulation Scripts**
    * `P_flat_simulation.m`: Simulates SGD dynamics to calculate the convergence probability towards the flatter valley.
    * `Phase_diagram.m`: Generates phase diagrams for Convergence Probability and Freezing Time under linear noise scaling.
    * `Phase_diagram_C_H_squared.m`: Generates phase diagrams under quadratic noise scaling to test model robustness.
    * `Fig4_data_generation.m`: Generates the simulation data (flat-valley probability `P_flat(y)`, freezing markers, and trajectories) used in the revised Fig. 4 panels.
* **Data Files**
    * `result_PhsDgm_*.mat`: Pre-computed phase-diagram results (kept in the repo) used to reproduce the toy-model figures.
    * Larger regenerable outputs (`P_right_*.mat`, `Fig4_simulation_data.mat`) are not version-controlled; recreate them by running the scripts above.

### 3. `Plot_figures/`
MATLAB scripts (and one Jupyter notebook) that reproduce every figure in the main text and Supplementary Information (SI). Each script writes its panels to `Figures/<figure_name>/`.

* **Main text:** `Fig1_transient_freezing.m`, `Fig2_freezing_control.m`, `Fig3_toy_model.m`, `Fig4_analytic_model_revised.m`.
* **Supplementary:** `Fig1S_solution_valleys.m`, `Fig1S_linear_inerpolation.ipynb`, `Fig2S_solution_properties.m`, `Fig3S_early_stage_dynamics.m`, `Fig4S_freezing_time.m`, `Fig5S_cnn_cifar10.m`, `Fig6S_toy_model_H2.m`.
* **Helpers:** `viridis.m`, `mycolormap.mat`, `Violin.m`, `violinplot.m`.

## 🚀 Usage Examples

### 1. Numerical Experiments (PyTorch)

First, navigate to the experiment directory:

```bash
cd Numerical_experiments

```

#### A. Train MLP on MNIST Subset

Runs repeated training on a 1,000-sample subset of MNIST.

* **Total Iterations: 100 / learning_rate**  

```bash
python run_repeat_mlp.py \
   --dataset_name MNIST \
   --batch_size 50 \
   --learning_rate 0.01 \
   --total_iterations 10000 \
   --total_realizations 20 \
   --train_num 100 \
   --test_num 20

```

#### B. Train CNN on CIFAR-10

Runs repeated training on the full CIFAR-10 dataset.

* **Total Iterations: 1000 / learning_rate:** 

```bash
python run_repeat_cnn.py \
   --dataset_name CIFAR10 \
   --batch_size 50 \
   --learning_rate 0.01 \
   --total_iterations 100000 \
   --total_realizations 10 \
   --train_num -1 \
   --test_num -1 \
   --hidden_num 128 \
   --save_checkpoint_dir ./save_checkpoint_cnn \
   --save_data_dir ./save_data_cnn

```

#### C. Continuation Training

Resumes training from a specific checkpoint using full-batch Gradient Descent (GD) to identify the local basin of attraction.

```bash
python continue_training.py \
   --batch_size 1000 \
   --learning_rate 0.05 \
   --total_iterations 2000 \
   --load_batch_size 50 \
   --load_learning_rate 0.05 \
   --train_num 100 \
   --test_num 20 \
   --load_realization 1 \
   --load_iteration_list 0 20 40 100

```

### 2. Theoretical Simulations (MATLAB)

Open the `Two_valleys_model/` folder in MATLAB:

* **Phase Diagrams:** Run `Phase_diagram.m` and `Phase_diagram_C_H_squared.m` to reproduce the phase diagrams for both standard and quadratic noise scaling models.
* **Dynamics Simulation:** Run `P_flat_simulation.m` to simulate SGD dynamics and compare numerical results with theoretical predictions.
